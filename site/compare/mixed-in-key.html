Solco andMixed In Key

Mixed In Key is the app many DJs first used to put keys on their tracks. It analyses each file for key, tempo and energy, sets cue points and hands the results to your DJ app. Solco works out keys too, as one step of preparing a whole library: grids, character, tags, duplicates, playlists and the USB drive.

I make Solco, so keep that in mind. This page compares what each one does, not how well. Every line about Mixed In Key comes from its own site, listed under Sources with the date I checked it.

3Where Solco does more

The rest of the prep.

  • Beat grids. Solco grids every track, follows tempo changes, finds downbeats and lists only the grids worth checking. S3 Mixed In Key's guides leave the grid to your DJ app. M4
  • More readings from the audio. Besides energy, Solco estimates style, mood, vocals and more, each searchable. S4
  • Tags, covers and duplicates. Tags and covers from the music catalogues, reviewed before anything is written, and duplicates found by their sound. S7 S8
  • Smart playlists and a gig planner. Saved searches that fill themselves, and an assistant that proposes a folder of playlists for the night. S5 S6
  • The USB itself. Solco writes the drive your Pioneer players read. S9 Mixed In Key works through your DJ app. M1
  • Linux. Solco runs on Linux as well as Mac and Windows. S10

4Where Mixed In Key does more

Cues, and the creative side.

  • Automatic cue points, up to eight per track, sent into rekordbox, Serato, Traktor and VirtualDJ. M2 M11 Solco doesn't set cues for you. S14
  • Energy across the track. Mixed In Key shows the energy level of each section. M3
  • Serato, VirtualDJ and Engine DJ. It sends keys and energy into those apps, and cues into Serato and VirtualDJ. M10 M11 Solco gives them only playlists. S11
  • Pro's creative tools: two decks, mashup and mixout ideas, stems, pitch shifting and loops. M2
  • It's established. Mixed In Key is on version 11. Solco is in private beta. M14

5Together

Using both.

You can, with one rule: let one app own the key. Both write a key into your files S15 M5, so if both run, the last one to write wins. Solco lets you turn off Write keys to files and put your files' own keys back, in Settings › Analysis. S15

A path I haven't tested end to end: analyse in Mixed In Key and send its cues into rekordbox as its guide describes M4, then import that rekordbox library into Solco, which brings hot cues and memory cues across S2, and let Solco grid, tag and write the USB.

Questions

What DJs ask about Solco and Mixed In Key.

Is Solco a Mixed In Key alternative?

If what you want is a library ready to play, with keys as one part of it, it can be. If you want automatic cue points or Pro's mashup tools, no.

Does this page compare key detection?

No. It compares which features each app has, not how well either one detects keys.

Which key notation does Solco show?

Alphanumeric, like 8A (the same 1A to 12B notation Mixed In Key calls Camelot), or classical, like Am, chosen under Key names in Solco's settings. A search such as key:8A works either way, and the file's key tag gets the standard notation other apps read.More in the help centre

Does Solco change my files?

It writes its own ID tag so it can follow moved files, and its key, which you can turn off. Every other tag waits until you apply it.More in the help centre
