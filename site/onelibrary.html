Solco · OneLibrary

Two libraries.One stick

Pioneer DJ and AlphaTheta players read one of two libraries on a USB stick. The CDJ-3000X, XDJ-AZ, OPUS-QUAD and OMNIS-DUO read only OneLibrary. The CDJ-3000, CDJ-2000NXS2, XDJ-RX3 and older players read only the Device Library.

A stick with just one of them leaves half the booth saying it can't find your music. Solco writes both on every stick, so you don't need to know which players a club has.

4rekordbox sticks

A stick rekordbox made stays rekordbox's.

Solco adds its tracks and playlists beside rekordbox's, in whichever libraries the stick has, and leaves rekordbox's tracks, playlists and played sets as they were. A stick whose only library is OneLibrary gets Solco's tracks in OneLibrary only, so players that read the Device Library won't list them; the export plan says so first. How the export works.

Questions

What DJs ask about OneLibrary.

What is OneLibrary?

The newer library format Pioneer DJ and AlphaTheta players read from a USB stick, in the file exportLibrary.db. rekordbox called it Device Library Plus until version 7.2.5. The CDJ-3000X, XDJ-AZ, OPUS-QUAD and OMNIS-DUO read only OneLibrary.More in the help centre

Does the CDJ-3000X read the Device Library?

Not according to AlphaTheta's notice of 18 March 2026: it lists the CDJ-3000X with the players that read only OneLibrary. A stick with only the Device Library shows no tracks on it. Every Solco stick has both.More in the help centre

Will a stick with both libraries still work on a CDJ-2000NXS2?

Yes. Older players read the Device Library and ignore the OneLibrary file beside it. Solco sticks with the Device Library have played on the CDJ-2000NXS2, CDJ-2000, XDJ-RX3, XDJ-1000MK2 and CDJ-3000.More in the help centre

Can I write only one library?

Yes. Open Options on the Export page and choose Classic or Newer under Libraries on the drive. Players that read the other library won't list the tracks.More in the help centre

Does it take twice as long?

No. Both libraries share the audio, grids, cues, waveforms and covers, so the second one adds a few seconds and a little space.
