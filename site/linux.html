CDJ USBs,made on Linux

rekordbox lists only Windows and macOS (its system requirements), so DJs on Linux have kept a second computer, a virtual machine or a Wine setup just to write a USB stick. Solco runs on Linux natively, and writes the stick your CDJs and XDJs read.

The same app as on a Mac or Windows: beat grids, key, loudness and character, tags and covers, duplicates, playlists and the USB export.

1Install

A package, not a workaround.

Each release has a .deb for Debian and Ubuntu, an .rpm for Fedora and similar distributions, and a portable archive you unpack anywhere. For 64-bit x86 and ARM64. Everything Solco needs to analyse your music is inside.

# Debian and Ubuntu
$ sudo apt install ./solco-*.deb
# Fedora and similar
$ sudo dnf install ./solco-*.rpm
$ solco

Packages install Solco under /opt/solco with a desktop entry and the solco command. Your library lives in ~/.local/share/solco, settings in ~/.config/solco. An installed package tells you the command that updates it.

2Analysis

Your music stays on your machine.

Solco analyses every track on your computer, on a supported graphics card when there is one and on the processor otherwise: the beat grid and downbeats, key, loudness, energy, style and the rest. Nothing is uploaded, and there's no account.

3On the USB

No Wine.
No VM.

The stick the players read, from Linux.

Solco writes both libraries Pioneer players read, the Device Library and OneLibrary, with grids, cues, waveforms, artwork and playlists. How the export works.

  • FAT32 at any size. Erase and prepare drive formats a stick the way every player reads it, after your system asks for an administrator's permission.
  • exFAT too. For the newer players, with your distribution's exFAT tools (the exfatprogs package).
  • Your rekordbox library comes along. Import rekordbox 6 or 7 from an XML export, or straight from a stick rekordbox made.
  • Traktor and M3U8. A Traktor collection with cues, loops and grids, and M3U8 playlists for other apps.

4Good to know

Plainly, for Linux.

Distributions
Packages for Debian, Ubuntu, Fedora and their relatives; the portable archive for the rest.
In the background
Keeping Solco running with its window closed needs a desktop that shows tray icons.
Mixing
Solco prepares your music and writes the stick; you play on the players. For mixing on Linux itself, use a DJ app that runs there.

Questions

What Linux DJs ask.

Does rekordbox run on Linux?

rekordbox's system requirements list Windows and macOS only. Solco runs on Linux natively and writes the USB stick Pioneer CDJ and XDJ players read, so you don't need rekordbox, Wine or a virtual machine for the stick.More in the help centre

Which distributions does Solco support?

64-bit x86 and ARM64 Linux. Each release has a .deb for Debian and Ubuntu, an .rpm for Fedora and similar distributions, and a portable .tar.gz archive you unpack anywhere and run solco from.More in the help centre

Can I import my rekordbox library on Linux?

Yes: from rekordbox's XML export, or from a USB stick rekordbox made. Playlists, folders, hot cues, memory cues, loops, ratings and colours come over. Your rekordbox library is only read, never changed.More in the help centre

Does analysis use my graphics card?

When there is a supported one. Otherwise Solco analyses on the processor, which is slower. On some integrated graphics, analysis can make the interface stutter.More in the help centre

Can I mix in Solco?

No. Solco has one deck for previewing, checking grids and setting cues. It prepares your music and writes the stick, and you play on the CDJs or XDJs.More in the help centre
